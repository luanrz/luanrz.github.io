附录 ​

基于 cc-switch 管理大模型配置 ​

安装 cc-switch：

shell
sudo pacman -S cc-switch

配置 Claude Code 大模型 ​

为 Claude Code 配置本地大模型（llama.cpp、Ollama 等），配置第三方大模型平台的方式与之类似。

json
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://127.0.0.1:8080",
    "ANTHROPIC_AUTH_TOKEN": "EMPTY",
    "ANTHROPIC_MODEL": "modelscope.cn/Qwen/Qwen2.5-Coder-7B-Instruct-GGUF"
  }
}

也可以设置环境变量达到一样的效果：

shell
export ANTHROPIC_BASE_URL=http://127.0.0.1:8080
export ANTHROPIC_AUTH_TOKEN=EMPTY
export ANTHROPIC_MODEL="modelscope.cn/Qwen/Qwen2.5-Coder-7B-Instruct-GGUF"

配置 OpenAI Codex 大模型 ​

为 OpenAI Codex 配置本地大模型（llama.cpp、Ollama 等），配置第三方大模型平台的方式与之类似。

~/.codex/config.toml

toml
model_provider = "custom"
model = "qwen2.5-coder-7b-instruct-q4_k_m.gguf"
model_reasoning_effort = "high"
disable_response_storage = true

[model_providers.custom]
name = "custom"
wire_api = "responses"
requires_openai_auth = true
base_url = "http://127.0.0.1:8080"

~/.codex/auth.json

json
{
  "OPENAI_API_KEY": "EMPTY"
}

配置 OpenCode 大模型 ​

为 OpenCode 配置本地大模型（llama.cpp、Ollama 等），配置第三方大模型平台的方式与之类似。

CC-Switch配置JSON

json
{
  "npm": "@ai-sdk/openai-compatible",
  "options": {
    "baseURL": "http://127.0.0.1:8080",
    "apiKey": "EMPTY",
    "setCacheKey": true
  },
  "models": {
    "qwen2.5-coder-7b-instruct-q4_k_m.gguf": {
      "name": "qwen2.5-coder-7b-instruct-q4_k_m.gguf"
    }
  }
}

~/.config/opencode/opencode.json

json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "local": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "http://127.0.0.1:8080",
        "apiKey": "EMPTY",
        "setCacheKey": true
      },
      "models": {
        "qwen2.5-coder-7b-instruct-q4_k_m.gguf": {
          "name": "qwen2.5-coder-7b-instruct-q4_k_m.gguf"
        }
      }
    }
  }
}

另外，也可使用 connect 命令连接第三方大模型：

  • 启动opencode
  • 输入/connect
  • 选择provider，如：DeepSeek
  • 输入API KEY，如：sk-xxxxxx

  "baseUrl": "http://127.0.0.1:8080",
  "api": "openai-completions",
  "apiKey": "EMPTY",

基于 ACP 协议连接任意 Agent CLI ​

ACP 协议定义了编辑器与 Agent 之间的标准通信接口。通过ACP协议，可以在任意 Client 中注册并使用任意 Agent ，这些 Agent 的注册信息可以在 ACP Registry 中找到。

以 Jetbrains 为例，可以使用官方提供的 ACP Registry 快速配置 ACP，随后在 AI Chat 中使用对应 Agent 。如果有个性化需求，如：

  • 官方ACP Registry 只支持Qoder国际版，需要使用国内版 Qoder CLI
  • IDEA 与 PyCharm 对同一个 ACP Agent 会冗余缓存两份，需要节省硬盘空间。

可考虑手工指定 ACP 配置，编辑下述 ~/.jetbrains/acp.json 文件（点击 AI Chat 右上角 Options 按钮的 Add Custom Agent 选项自动生成），如下所示：

json
{
  "agent_servers": {
    "Qwen Code": {
      // npm install -g @qwen-code/qwen-code
      "command": "~/.local/bin/qwen",
      "args": [
        "--acp",
        "--experimental-skills"
      ]
    },
    "Qoder CN CLI": {
      // npm i -g @qodercn-ai/qoderclicn
      "command": "~/.local/bin/qoderclicn",
      "args": [
        "--acp"
      ]
    },
    "Codebuddy Code": {
      // npm install -g @tencent-ai/codebuddy-code
      "command": "~/.local/bin/codebuddy-code",
      "args": [
        "--acp"
      ]
    },
    "OpenCode": {
      // npm i -g opencode-ai
      "command": "~/.local/bin/opencode",
      "args": [
        "acp"
      ]
    },
    "Pi": {
      // npm install -g pi-acp
      "command": "~/.local/bin/pi-acp"
    }
  },
  "default_mcp_settings": {}
}
