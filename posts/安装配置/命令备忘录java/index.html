Java序列化#

new ObjectOutputStream(new FileOutputStream("resp")).writeObject(resp);

支持AspectJ切面编程#

配置JVM参数javaagent以支持切面编程：

java -javaagent:${HOME}/.m2/repository/org/aspectj/aspectjweaver/1.9.4/aspectjweaver-1.9.4.jar app.jar

启用远程调试#

java -jar \
-Dserver.port=8080 \
-agentlib:jdwp=transport=dt_socket,server=y,suspend=n,address=8081 \
parent-0.0.1-SNAPSHOT.jar

jasypt加密解密#

java -cp jasypt-1.9.2.jar org.jasypt.intf.cli.JasyptPBEStringEncryptionCLI input=123456 password=1234-1234-1234-1234 algorithm=PBEWithMD5AndDES

java -cp jasypt-1.9.2.jar org.jasypt.intf.cli.JasyptPBEStringDecryptionCLI input="jvp0W0qUkv0WmG/JzwyUTA==" password=1234-1234-1234-1234 algorithm=PBEWithMD5AndDES

诊断CPU或内存占用过高的问题#

（1）基于jps查看进程号

jps -l

参考输出结果（以实际为准）：

70791 jdk.jcmd/sun.tools.jps.Jps
70744 daily-api-0.1.0-SNAPSHOT.jar

需要处理的应用对应的进程号是70744：

PID=70744

（2）基于top查看进程信息

top -p $PID

参考输出结果（以实际为准）：

    PID 用户      优  NI    虚拟   驻留   共享 S  %CPU  %MEM     时间+ 命令                                                                                                                            
  70744 luanrz    20   0 6346796 522696  28840 S  20.6   3.2   0:56.22 java

重点关注进程的%CPU和%MEM是否异常。如果有异常，继续往下执行。

（3）基于top查看线程信息

top -H -p $PID

参考输出结果（以实际为准）：

    PID 用户      优  NI    虚拟   驻留   共享 S  %CPU  %MEM     时间+ 命令

  70857 luanrz    20   0 6346796 523116  28840 S   1.7    3.2   0:01.51 http-nio-8080-e                                                                                                               
  ...（其它线程）

重点关注%CPU和%MEM位于前列的线程，当前需要处理的线程号是70852：

TID=70852
TID16=$(printf "%x" $TID) #16进制的TID

（4）基于jstack查看线程堆栈信息

# 适用于JDK8
jstack $PID | grep -A 30 "nid=0x$TID16"
# 适用于最新的JDK（JDK18及之后，详见：https://bugs.openjdk.org/browse/JDK-8268425）
jstack $PID | grep -A 30 "nid=$TID"
