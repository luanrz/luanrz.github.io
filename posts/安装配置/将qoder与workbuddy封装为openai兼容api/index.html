将 Qoder 与 WorkBuddy 封装为 OpenAI 兼容 API。

Qoder CN#

qoder-proxy#

（1）下载源码

mkdir avaritiachaos
cd avaritiachaos
git clone https://github.com/avaritiachaos/qoder-proxy
cd qoder-proxy

（2）配置

npm install -g @qodercn-ai/qoderclicn
npm install
cp .env.example .env

编辑 .env 配置文件：

PROXY_API_KEY=EMPTY
CLI_BACKEND=cn
QODERCN_PERSONAL_ACCESS_TOKEN=pt-xxxxxx

QODERCN_PERSONAL_ACCESS_TOKEN 配置可从 Qoder 官方服务集成页面获取。

（3）启动与验证

npm start

对于windows的启动，可将 start-ui.cmd 发送到桌面快捷方式，并重命名为 qoder-proxy.cmd。

随后按照下述流程进行验证：

  • 浏览器打开 http://127.0.0.1:3000/ui/
  • 在 Config 菜单栏中，设置 Proxy API Key 项为 EMPTY（同上述 .env 配置文件中的 PROXY_API_KEY）
  • 在 Chat Test 菜单栏中，发送任意消息验证连通性
  • 在 OpenAI 兼容客户端中配置 API 地址 http://127.0.0.1:3000，进一步验证功能

WorkBuddy / CodeBuddy#

workbuddy2api#

（1）下载源码

mkdir Sliverkiss
cd Sliverkiss
git clone https://github.com/Sliverkiss/workbuddy2api
cd workbuddy2api

（2）配置

构建二进制文件（Linux / MacOS）：

CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o wb2api ./cmd/server
CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o signin_bin ./cmd/signin
CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o login ./cmd/login
CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o credit ./cmd/credit

构建二进制文件（Windows）：

go build -trimpath -ldflags="-s -w" -o wb2api.exe ./cmd/server
go build -trimpath -ldflags="-s -w" -o login.exe ./cmd/login
go build -trimpath -ldflags="-s -w" -o signin_bin.exe ./cmd/signin
go build -trimpath -ldflags="-s -w" -o credit.exe ./cmd/credit

生成 workbuddy2api 的 config.json 配置文件：

cp config.example.json config.json

编辑 config.json 配置文件：

{
  "listen": "127.0.0.1:7863",
  "api_key": "EMPTY",
}

（3）启动

./wb2api

对于windows，可使用 start-workbuddy2api.cmd 命令启动服务。

验证流程与鉴权配置，详见workbuddy2api-gui。

workbuddy2api-gui#

（1）下载源码

mkdir 287775856
cd 287775856
git clone https://github.com/287775856/workbuddy2api-gui
cd workbuddy2api-gui

（2）配置

# 1. 构建前端
cd web 
npm install 
npm run build 
cd ..

# 2. 构建二进制文件 （Windows下将 wbgui 修改为 wbgui.exe）
go build -o wbgui ./cmd/server

生成 workbuddy2api-gui 的 config.json 配置文件：

cp config.example.json config.json

编辑 config.json 配置文件：

{
  "listen": "127.0.0.1:8787",
  "auth_dir": "../../Sliverkiss/workbuddy2api/auths",
  "config_file": "../../Sliverkiss/workbuddy2api/config.json",
  "ui": {
    "password": "admin",
  }
}

（3）启动与验证

# 启动（Windows下将 wbgui 修改为 wbgui.exe）
./wbgui

随后按照下述流程进行验证：

  • 浏览器打开 http://127.0.0.1:8787
  • 根据页面引导添加账号
  • 在聊天测试中发送任意消息验证连通性
  • 在 OpenAI 兼容客户端中配置 API 地址 http://127.0.0.1:7863，进一步验证功能

（4）支持同时启动 workbuddy2api 与 workbuddy2api-gui

对于 Linux/MacOS 新建 workbuddy2api.sh 脚本：

#!/bin/sh
API_DIR="$HOME/Data/Code/public/Sliverkiss/workbuddy2api"
GUI_DIR="$HOME/Data/Code/public/287775856/workbuddy2api-gui"

echo "[1/2] 启动 API 服务..."
cd "$API_DIR"
./wb2api  &

echo "[2/2] 启动 GUI..."
cd "$GUI_DIR"
./wbgui  &

对于 Windows 新建 workbuddy2api.cmd 脚本：

@echo off
chcp 65001 >nul
title workbuddy2api

rem ========== 配置区 ==========
set "API_DIR=D:\Code\public\Sliverkiss\workbuddy2api"
set "GUI_DIR=D:\Code\public\287775856\workbuddy2api-gui"
rem ============================

echo [1/2] 启动 API 服务...
cd /d "%API_DIR%"
call "start-workbuddy2api.cmd"

echo.
echo [2/2] 启动 GUI...
cd /d "%GUI_DIR%"
wbgui.exe

pause
