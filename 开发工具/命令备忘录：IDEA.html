系统快捷键清除 ​

1）XFCE：

  • XFCE设置-窗口管理器-键盘
    • Alt F4/F6-F12
    • Ctrl F1-F12
    • Ctrl Alt 上/下/左/右
  • XFCE设置-键盘-应用程序快捷键
    • Ctrl Alt L -> Super + L

2）GNOME：

清除Ctrl Alt 上/下/左/右：

shell
gsettings set org.gnome.desktop.wm.keybindings switch-to-workspace-left "['']"
gsettings set org.gnome.desktop.wm.keybindings switch-to-workspace-right "['']"
gsettings set org.gnome.desktop.wm.keybindings switch-to-workspace-up "['']"
gsettings set org.gnome.desktop.wm.keybindings switch-to-workspace-down "['']"

移除IDEA和PyCharm中的"Start Free Trial"按钮 ​

详见Jetbrains官方Issue

（1）进入IDEA或PyCharm的lib目录

  • Linux IDEA：cd ~/.local/share/JetBrains/Toolbox/apps/intellij-idea/lib
  • Linux PyCharm：cd ~/.local/share/JetBrains/Toolbox/apps/pycharm/plugins/pycharm-pro-customization/lib/modules
  • MacOS IDEA：cd ~/Applications/IntelliJ\ IDEA.app/Contents/lib
  • MacOS PyCharm：cd ~/Applications/PyCharm.app/Contents/plugins/pycharm-pro-customization/lib/modules
  • Windows IDEA：cd 'C:\Users\luanr\AppData\Local\Programs\IntelliJ IDEA\lib\'
  • Windows PyCharm：cd 'C:\Users\luanr\AppData\Local\Programs\PyCharm\plugins\pycharm-pro-customization\lib\modules\'

（2）删除或重命名trialPromotion文件

  • mv intellij.platform.trialPromotion.common.jar intellij.platform.trialPromotion.common.jar.bak
