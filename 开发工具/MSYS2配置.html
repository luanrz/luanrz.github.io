MSYS2配置 ​

MSYS2 是 Windows 下的一款 Linux 环境开发平台。

一、安装 ​

通过 官网 下载并安装 MSYS2。

安装目录指定为：%LOCALAPPDATA%/Programs/msys64/。

二、配置 Windows Terminal 集成 ​

参见 MSYS2 Documentation - Terminals。

在 Windows Terminal 设置中，点击左下角【打开 JSON 文件】，修改如下 settings.json 配置：

json
{
    "defaultProfile": "{17da3cac-b318-431e-8a3e-7fcdefe6d114}",
    "profiles": {
        "list": [
            // ...
            {
                "commandline": "%LOCALAPPDATA%/Programs/msys64/msys2_shell.cmd -defterm -here -no-start -ucrt64",
                "guid": "{17da3cac-b318-431e-8a3e-7fcdefe6d114}",
                "icon": "%LOCALAPPDATA%/Programs/msys64/ucrt64.ico",
                "name": "MSYS2 UCRT64",
                "startingDirectory": "%USERPROFILE%"
            },
            // ...
        ]
    }
}

后续在 Windows Terminal 软件中，将默认以 MSYS2 UCRT64 配置启动。

三、配置国内镜像 ​

将 mirrorlist 中的 ustc / tsinghua 等国内镜像挪到前面：

shell
cd /etc/pacman.d/
vim mirrorlist.msys
vim mirrorlist.mingw

验证下载速度：

shell
pacman -Syu

四、安装常用软件 ​

shell
# neovim
pacman -S mingw-w64-ucrt-x86_64-neovim
# git
pacman -S mingw-w64-ucrt-x86_64-git
# gcc
pacman -S mingw-w64-ucrt-x86_64-gcc
# python
pacman -S mingw-w64-ucrt-x86_64-python
# diffutils (diff)
pacman -S mingw-w64-ucrt-x86_64-diffutils

# vim
pacman -S vim
# ncdu
pacman -S ncdu
# rsync
pacman -S rsync

# 列出所有单独指定安装的软件包
pacman -Qe

五、配置 ZSH ​

（1）安装 zsh

shell
pacman -S zsh

在 Windows Terminal 的 settings.json 中，给 commandline 加上 -shell zsh 参数：

json
{
    "profiles": {
        "list": [
            {
                "commandline": "%LOCALAPPDATA%/Programs/msys64/msys2_shell.cmd -defterm -here -no-start -ucrt64 -shell zsh"
            },
        ]
    }
}

（2）安装 oh-my-zsh 与 powerlevel10k 主题

shell
# 安装 oh-my-zsh
REMOTE=https://gitee.com/mirrors/oh-my-zsh.git sh -c "$(curl -fsSL https://gitee.com/mirrors/oh-my-zsh/raw/master/tools/install.sh)"
# 安装 powerlevel10k 主题
git clone --depth=1 https://gitee.com/romkatv/powerlevel10k.git ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/themes/powerlevel10k
# 配置 powerlevel10k 主题
sed -i 's/^ZSH_THEME=.*/ZSH_THEME="powerlevel10k\/powerlevel10k"/' ~/.zshrc
# 刷新配置（此时会进入 powerlevel10k 配置界面）
source ~/.zshrc

（3）配置 powerlevel10k 主题的字体

按需安装 powerlevel10k 主题所需的 MesloLGS NF 等 Nerd Font 字体，以避免终端中的图标出现方块或问号。

下载 MesloLGS NF 字体：

shell
wget https://github.com/romkatv/powerlevel10k-media/raw/master/MesloLGS%20NF%20Regular.ttf

在 Windows 文件资源管理器中双击 MesloLGS NF Regular.ttf 文件以安装对应字体。

在 Windows Terminal 的 settings.json 中，新增 font 配置：

json
{
    "profiles": {
        "list": [
            {
                "font": {
                    "face": "MesloLGS NF",
                    "size": 12
                }
            },
        ]
    }
}

重新配置 powerlevel10k：

shell
p10k configure
